# Vision — Project Tat Tvam Asi

本项目是一次有限的工程实验：用 Rust 的类型与所有权纪律，近似表达中观对「无自性」与「缘起」的观察。
它不声称掌握宇宙本质，也不提供解脱。它只试图在硅上减少一类可避免的混乱。

---

## 1. 无自性与所有权

现象因缘而起，无独立自性（svabhāva）。
在程序里，这对应：值有明确的所有者与确定的终结；不假设数据「自己存在」于某个隐式共享空间。

垃圾回收与隐式共享并非错误，它们只是另一种缘起方式。本项目选择编译期所有权，是为了在特定路径上让「生灭」可见、可审计，而不是断言它更高贵。

---

## 2. 不落两边与穷尽匹配

中观避免「有」与「无」的极端。
在代码里，这对应：尽量不留下未命名的状态与静默忽略的分支。`match` 穷尽，不是为了掌控一切，而是承认：未被处理的分支仍是缘起的一部分，不应被假装不存在。

「绝对不会崩溃」是不可达的。规格错误、侧信道、硬件故障、运维失误仍然存在。我们只处理能在类型层面显式约束的那一类。

---

## 3. 空性与零成本抽象

空不是断灭，而是无自性。高层结构（泛型、迭代器、宏）可以存在，却不必在运行时留下固定实体。
零成本抽象是这种观察的一种工程近似：形式可以丰富，负担可以趋近于无。它仍然依赖编译器、架构与具体场景，并非普遍真理。

---

## 边界

- 本项目不替代其他语言或范式。
- 它不为任何个人或化身建立哲学中心。
- 它不承诺拯救能耗、终结漏洞或恢复程序员尊严。
- 若它有用，用处来自具体约束与可检验的行为，而非叙事。

Tat Tvam Asi —— 在依赖中显现，在空性中不执。
